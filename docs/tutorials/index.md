# Tutorials

The tutorials teach the client in order, from the first query to a frozen cohort with its citations. Each one is
a notebook that tells one part of the story: what the step is for, the code with its real output, and the
mistakes that give wrong results without an error. Start with the overview, which runs the whole path on one page
and links each step to the tutorial that covers it.

Every tutorial reads the catalog release of 2026-10-28, so the numbers on these pages match what you get when you
run the notebooks yourself. The datasets they download are small, about 50 MB in total.
